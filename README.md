# LabelFlow

LabelFlow раскладывает фотографии по цветовым меткам и звёздам. Программа смотрит JPG в выбранной папке, читает метку и рейтинг и выполняет действие из настроек: переносит файлы в папку или открывает их в программе.

Меню стоит в Проводнике: правый щелчок по папке, пункт **LabelFlow**. В Windows 11 оно находится в классическом меню — Shift+правый щелчок или «Показать дополнительные параметры». Значок в трее открывает настройки двойным щелчком.

## Что учитывается

Сначала берётся метка из самого файла, `xmp:Label`: Красный, Оранжевый, Желтый, Зеленый, Синий, Розовый, Пурпурный. Если в файле цветовой метки нет, используется цвет из каталога XnView. Звёзды читаются из файла (`xmp:Rating`, рейтинг Windows и EXIF) и, если там их нет, из каталога XnView.

Сканируются только JPG и JPEG в самой папке, без вложенных папок. Уже существующий файл в папке назначения не перезаписывается. Метаданные снимка программа не меняет.

## Настройки

В таблице у каждого цвета и у каждой звезды от 1★ до 5★ одно действие: переместить в папку, открыть программу или ничего не делать.

Папку для перемещения можно задать тремя способами:

- выбрать существующую папку;
- создать её рядом с фотографиями, внутри сканируемой папки;
- создать её рядом со сканируемой папкой.

Пункт **Запустить все** выполняет все заданные действия за один проход. Галочка **Запуск вместе с Windows** включает автозапуск для текущего пользователя.

По умолчанию зелёные фотографии переносятся в папку «Подрядчики» рядом со сканируемой, а оранжевые открываются в Photoshop.

## Установка

Нужна Windows. Готовая программа лежит в `dist\LabelFlow.exe`.

Контекстное меню для текущего пользователя, без прав администратора:

```bat
install_context_menu.bat
```

Удаление пункта меню:

```bat
uninstall_context_menu.bat
```

Запуск `LabelFlow.exe` без параметров показывает значок в трее. Настройки хранятся в `%APPDATA%\LabelFlow\config.json`.
